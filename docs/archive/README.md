# Historical implementation records

The [38 implementation prompts](prompts/README.md) were archived on 2026-10-29
after their implementation and final reviews. Their requirements and stage order
are preserved for traceability. Links were updated for the new location.

For current use and maintenance, read the [documentation index](../README.md),
[engineering contracts](../prompts/README.md) and [AGENTS.md](../../AGENTS.md).
The [progress ledger](../implementation-progress.md) and
[validation history](../validation.md) retain dated outcomes. An old PASS applies
only to the source, tools and scope recorded with it.

The archive is source-checkout material and is excluded from ordinary packages.
